# Tic-Tac-Toe (Java CLI)

A command-line Tic-Tac-Toe game built in Java as part of my backend developer learning path.

## Features
- 3x3 grid playable by two players (X and O)
- Input validation (rejects non-numbers)
- Prevents playing on an already-taken cell
- Detects wins (rows, columns, diagonals) and draws

## How to run
1. Clone the repo
2. Open in IntelliJ (or compile with `javac Main.java`)
3. Run `Main.java`
4. Enter row and column (1-3) when prompted

## What I learned
- Java OOP basics: classes, constructors, static vs. instance
- 2D arrays
- Exception handling with try/catch
- Reading user input with Scanner
